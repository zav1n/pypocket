# PyPocket：零成本 Python 学习 PWA

面向零基础自学、也适合带新手入门的跨平台 Web App（PWA）。
**核心：0 服务器费用、0 运维负担、纯前端架构，Python 直接在浏览器里跑。**

- 线上地址：https://pypocket.pages.dev
- 当前版本：**v1.0.0**（更新于 2026-10-30，共 49 关）
- 怎么确认自己用的是不是最新版：打开 App 右上角「设置」→ 版本栏，对照下面
  「更新日志（Release）」里最新一条的版本号和日期。

## 快速开始：怎么使用

### 1. 打开就能练

- 直接打开线上地址，或本地运行（见下面「本地运行」）。
- 第一次点「运行」会从 jsdelivr CDN 下载 Pyodide（约 10MB），之后浏览器会缓存。
- 手机上用浏览器打开后选「添加到主屏幕」，就是全屏 App 体验。

### 2. 顶部六个入口

| 入口 | 用来干什么 |
| --- | --- |
| 📖 学习做题 | 主线：按路线一关一关做题、提交判题 |
| 🧪 自由练习场 | 没有关卡、没有判题，写什么都能跑，适合试代码、做变式 |
| 📕 错题本 | 只收录提交判题失败的题，失败次数多、上次失败久的排前面 |
| 🔥 打卡统计 | 今日打卡、连续打卡、累计天数、本周打卡、打卡日历、近 7 天柱状图、各路线进度、成就 |
| 🚀 第三阶段指南 | 只读指南：离开浏览器后，在自己电脑上做真实项目的步骤（见下面） |
| 🗺️ 学习路线与方法 | 7 个阶段的路线、难度阶梯、学习方法，每阶段可勾选完成 |

### 3. 做一关的完整流程

1. 在「学习做题」里先选路线（新手村 / 爬虫线 / 后端线 / AI 线 / 进阶篇 / 实战项目 /
   逻辑实战 / 教科书进阶），再选一关。
2. 读题：题面写了知识点和通关任务。
3. 在编辑器里写代码，点「运行」只看输出，不判题；点「提交判题」才算正式提交。
4. 通关：该关记为已通关，当天自动打卡，错题本里这题自动变成「已攻克」。
5. 没通过：只看报错，先自己定位（先读报错最后一行，再找自己写的那一行），
   这题会自动进错题本；点「去重练」会回到该关，编辑器直接载入上次失败的代码。
6. 卡住了：编辑器下方有「查看答案」，建议先看懂思路、关掉后自己重写一遍再提交；
   直接载入提交也能通关，但等于跳过了思考。
7. 想重做：点题目标题旁的「恢复初始代码」按钮（旋转箭头图标），拿到起手代码再做一遍。
   注意：实战项目 3 关曾原地升级变难，之前通关留下的旧代码可能通不过新判题，
   这种情况同样点「恢复初始代码」重做。
8. 上一关 / 下一关按钮在编辑器下方；不用跳关，后面每一关都默认前面关的概念已经会了。

### 4. 设置里能改什么

打开右上角「设置」：

- **你的名字**：用于区分打卡进度，换名字会换一套独立的打卡记录。
- **AI 助教**：选预设（硅基流动 / Gemini / 自定义）、粘贴自己领的 Key。
  Key 只存在你自己的浏览器 localStorage，不上传到本站服务器——本站本来就没有服务器。
  判题失败时点「问 AI 助教」才会把当前代码和报错发给你自己配置的 AI 服务商。
- **进度同步**：不配 Supabase 就只用本地浏览器保存；想多设备同步再按下面「可选：Supabase 同步进度」配置。
- **版本**：显示当前版本号、更新日期、总关卡数，对照 README 更新日志判断是否为最新版。

### 5. 建议的学习节奏

- 每天 1–3 关，通关比赶进度重要。
- 每关通关后立刻合上答案重写一遍（主动回忆），5 分钟就够。
- 错题隔天必练，隔周抽查一次已攻克的题（间隔重复）。
- 每个阶段结束时，用自己的话讲一遍这个阶段最难的 3 个概念（费曼讲解）；
  讲不出来就回到题头再读一遍，也可以在自由练习场里用注释把讲解写下来。
- 每周选 2 关做变式：把数字、名字、条件改掉，换数据还能过才算真会（默写与变式）。

### 7 个阶段（App 内「学习路线与方法」页，同款内容）

路线对照的是三本主流入门书的共同章节结构，不是抄某一本书的例题：
《Python 编程：从入门到实践》、廖雪峰《Python 教程》、
《Automate the Boring Stuff with Python》。
三本书都先讲变量、列表、字典、if、循环，再讲函数，再讲类，
再讲文件异常测试，最后讲实战项目——本 App 就是按这个顺序排的。

| 阶段 | 难度 | 本阶段关卡 | 过关自测 |
| --- | --- | --- | --- |
| 第 0 阶段：准备与第一行代码 | L1 · 概念 | 新手村第 1 关 + 第三阶段指南第 0 步 | 不查教程，能写出 print 和变量，并说出变量名是什么意思 |
| 第 1 阶段：基础语法 | L1 · 概念 | 新手村全部、爬虫线、后端线、AI 线、教科书第 1–3 关 | 给一段没见过的数据，能自己选列表还是字典、for 还是 if，并写出来 |

| 第 3 阶段：面向对象 | L2–L3 · 逻辑 + 项目 | 进阶篇类与对象 + 教科书第 9–10 关 + 逻辑实战第 5 关（图书馆借还） | 能说出“类是模板、对象是实例、继承是复用、多态是同一方法不同表现”，并自己写一个子类 |

每阶段在 App 里可以点圆圈勾选完成，勾选只存在浏览器 localStorage，换设备不跟着走。

### 难度阶梯：L1 → L4

难度不是堆行数，升的是组合复杂度：

- **L1 · 概念关**：2–10 行，算一个答案（新手村、爬虫线、后端线、AI 线、教科书第 1–3 关）。
- **L2 · 逻辑关**：多个函数、多步骤、有边界（逻辑实战第 1–8 关、进阶篇、教科书第 4–7、9 关）。
- **L3 · 调试 / 重构 / 项目关**：读代码、改代码、做系统（调试题、重构题、实战项目 3 个）。
- **L4 · 教科书进阶关**：需要组合前面所有知识（教科书第 8、10–14 关）。

### 学习方法：闯关是主线，另加 7 种

闯关玩法是主线，保留；下面 7 种是加在闯关之外的，不是替代闯关：

1. **主动回忆**：通关后合上答案，凭记忆重写一遍，写不出来再看答案，再重写。
2. **间隔重复**：错题本就是间隔重复的工具，今天错的题明天重练一次，下周再重练一次。
3. **费曼讲解**：通关后用自己的话讲一遍核心，讲不出来就回到题头再读一遍。
4. **调试驱动**：报错先读最后一行，先拿最短的数据试；每次报错先自己定位 5 分钟，
   实在找不到再问 AI 助教，而且只问思路、不直接要完整代码。
5. **重构阅读**：先读懂别人的乱代码，再动手拆：长函数拆成小函数、重复逻辑抽成一个函数、
   魔法数字换成有名字的常量。
6. **项目驱动**：每个阶段末至少做 1 个项目，把这个阶段的东西串起来。
7. **默写与变式**：通关后换一组数据、换一个需求再做一遍，换数据就错说明是背答案不是真会。

一句话总结：先闯关学会一个概念（输入），立刻合上答案重写一遍（主动回忆），
错了进错题本隔天重练（间隔重复），能用自己的话讲出来（费曼讲解），
每个阶段末做一个项目把概念串起来（项目驱动）。只看书、只看答案、只刷原题，这三种都不算学过。

### 逻辑实战线、调试题、重构题（第 3–4 阶段的重点）

和概念关的区别：有状态（判题按顺序调用多次，查每一步之后的状态）、
多步骤（前一步输出就是后一步输入，中间结果也要查）、
有边界（空数据、重复、库存不足、非法输入都要测）、给需求不给步骤（起手只给函数签名和 TODO）。

- 逻辑关 8 关：成绩管理、购物车结算、猜数字游戏、记账本、图书馆借还、
  爬虫进阶、后端进阶、数据进阶。
- 调试题 3 关：起手代码能跑但有 bug，每关只修一个 bug。
  买 2 件只算 1 件钱（循环里丢了 qty）、刚好 60 分也被算不及格（`<= 60` 和 `< 60` 的边界）、
  计数器每轮都被清空（初始化写进了循环里）。
- 重构题 3 关：起手代码能跑、结果也对，但写得乱，行为不能变，把代码拆干净。
  长函数拆成 subtotal / apply_discount / add_tax 三个小函数、重复的加税逻辑抽成 add_tax、
  魔法数字换成 PASS_SCORE / ADULT_AGE 等有名字的常量。判题同时查行为和小函数/常量是否存在，
  直接提交起手代码会失败——这就是重构题和普通题的区别。
- 逻辑关和项目关的编辑器也加高了（逻辑关 420px、项目关 340px，原来统一 260px），长代码写起来不那么挤。
- 每关同样有查看答案按钮。加新关卡时记得 `Lesson` 有必填字段 `solution`。

### 第三阶段：离开浏览器，做真实项目

顶部「第三阶段指南」是只读页，没有判题、不跑代码，
因为第三阶段需要在自己电脑上做真实网络、真实文件、真实服务器。
内容就是 `STAGE3.md` 的大纲：本地环境（venv / Git / VS Code）、
真实爬虫（requests / BeautifulSoup）、真实后端（FastAPI + SQLite）、
真实数据分析（pandas + matplotlib）、毕业闭环项目和常见坑。
每一步可以点圆圈勾选完成，勾选只存在浏览器 localStorage。

## 功能一览：打卡、错题本、自由练习场

全部存在浏览器 localStorage，0 服务器、0 费用，换用户名会换一套独立记录。

**打卡与学习统计、成就：**

- 顶部切换「学习做题 / 打卡统计」，统计页显示今日打卡、连续打卡、累计天数、本周打卡、已通关。
- 通关一关 = 当天自动打卡；没通关也可以在统计页点「今日打卡」手动打卡。
- 打卡日历（可翻月，绿色 = 打卡过，金色边框 = 今天）、近 7 天通关次数柱状图、各路线进度条。
- 成就 11 个：第一步、新手上路、新手村毕业、多面手、全部通关、三日连打、一周坚持、
  月度自律、累计 7 天、累计 30 天、单周 5 天。连续打卡成就按“最长连续”判定，
  断了一次不会把已解锁的成就收回。
- 注意：升级前已通关的关卡没有日期记录，只计入通关数，不补算打卡天数；
  打卡统计从升级后第一次通关 / 手动打卡开始算。

**自由练习场（顶部「自由练习场」）：**

- 没有关卡、没有判题，写什么都能跑；附 3 个示例（打招呼、循环、统计词频）。
- 当前代码自动存为草稿，刷新不丢；觉得有用的代码可以起名字保存为片段，随时载入接着改、删除。

**错题本（顶部「错题本」，有待复习数角标）：**

- 只有“提交判题失败”才自动记进来，单纯点“运行”报错不算，避免把试错都记成错题。
- 同一关多次失败只记一条，失败次数累加，并更新为最新一次的代码和报错。
- 通关该关后自动变成“已攻克”；也可以手动标记已攻克、删除、清空已攻克。
- 复习顺序：失败次数多、上次失败久的排前面。点“去重练”会回到该关，
  编辑器直接载入上次失败的代码，改对提交后自动变已攻克。

## 部署（任选其一，免费）

### Cloudflare Pages（推荐，当前线上就是它）

1. 把代码推到 GitHub（仓库：https://github.com/zav1n/pypocket，main 分支）。
2. Cloudflare Dashboard → Pages → 连接仓库。
3. 构建命令 `npm run build`，输出目录 `dist`，其余默认。
4. 每次 push 自动重新部署；部署完打开线上地址，到「设置」里核对版本号。

### Vercel

1. 导入 GitHub 仓库，框架选 Vite。
2. 构建命令 `npm run build`，输出目录 `dist`。
3. 部署完成即有免费 HTTPS 域名。

## 可选：Supabase 同步进度

1. 注册 https://supabase.com，新建免费项目。
2. 在 SQL Editor 运行：

```sql
create table user_progress (
  id bigint generated by default as identity primary key,
  user_name text not null,
  lesson_id text not null,
  submitted_code text,
  completed_at timestamp with time zone default timezone('utc'::text, now()),
  unique(user_name, lesson_id)
);
-- 演示用最简单的公开策略：生产环境请按自己需求收紧 RLS
alter table user_progress enable row level security;
create policy "open" on user_progress for all using (true) with check (true);
```

3. 在部署平台的环境变量里填 `VITE_SUPABASE_URL` 和 `VITE_SUPABASE_ANON_KEY`，重新部署。
4. 没填这两个变量时 App 自动只用本地存储，不会报错。

> 安全提醒：上面演示的 open 策略等于公开读写，只适合熟人小范围演示。
> 正式给多人用时，请改成按 `user_name` 或 Supabase Auth 鉴权后再放行。

## 加新关卡

只改 `src/data/courses.ts`，往 `COURSES` 里加一个对象（逻辑关放 `src/data/logicCourses.ts`，

```ts
{
  id: 'rookie-07',
  track: 'rookie', // rookie | spider | backend | ai | advanced | project | logic | textbook
  title: '第 7 关：…',

  testCode: `assert …`,
```

## 更新日志（Release）

### 每次更新的规则（以后每次发布都按这 4 步走）

1. **改版本号**：`src/version.ts` 里的 `APP_VERSION` 和 `package.json` 里的 `version` 同步改。
   编号规则：新路线 / 大功能升 minor（如 v1.0.0 → v1.1.0），小修小补升 patch（如 v1.0.0 → v1.0.1）。
   同时更新 `src/version.ts` 里的 `APP_BUILD_DATE`（发布日期）。
2. **App 里能看到**：发布后打开 App「设置」→ 版本栏，应显示新版本号、更新日期、总关卡数。
