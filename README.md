# PyPocket：零成本 Python 学习 PWA

面向个人学习与带教小白的跨平台 Web App（PWA）。**核心：0 服务器费用、0 运维负担、纯前端架构。**

## 免费清单（长期免费路线）

| 模块 | 方案 | 费用 |
| --- | --- | --- |
| 前端 | Vite + React + TS + Tailwind + CodeMirror | 0 |
| Python 引擎 | Pyodide（WebAssembly，浏览器本地跑 Python 3.11+） | 0，后端开销 0 |
| 进度打卡 | 默认浏览器 localStorage | 0，0 配置 |
| 进度同步（可选） | Supabase 免费版 500MB PostgreSQL | 0，不配也能用 |
| AI 助教（可选） | 硅基流动免费模型 / Gemini Flash 免费额度，Key 只存用户浏览器 | 0，Key 自领 |
| 部署 | Cloudflare Pages 或 Vercel，绑定 GitHub 自动构建 | 0，含免费 HTTPS |

**注意：不要把 AI Key 写进代码或 `.env` 提交到 GitHub。** Key 是在 App 右上角「设置」里由每个使用者自己填的，只存在他自己的浏览器里。

## 本地运行

```bash
npm install
npm run dev
npm run build   # 构建产物在 dist/
npm run preview # 本地预览构建产物
```

第一次点「运行」会从 jsdelivr CDN 下载 Pyodide（约 10MB），之后浏览器会缓存。手机上用浏览器打开后选「添加到主屏幕」，就是全屏 App 体验。

## 部署（任选其一，免费）

### Cloudflare Pages（推荐）
1. 把代码推到 GitHub。
2. Cloudflare Dashboard → Pages → 连接仓库。
3. 构建命令 `npm run build`，输出目录 `dist`，其余默认。
4. 每次 push 自动重新部署。

### Vercel
1. 导入 GitHub 仓库，框架选 Vite。
2. 构建命令 `npm run build`，输出目录 `dist`。
3. 部署完成即有免费 HTTPS 域名。

## 可选：Supabase 同步进度

1. 注册 https://supabase.com，新建免费项目。
2. 在 SQL Editor 运行：
```sql
create table user_progress (
  id bigint generated by default as identity primary key,
  user_name text not null,
  lesson_id text not null,
  submitted_code text,
  completed_at timestamp with time zone default timezone('utc'::text, now()),
  unique(user_name, lesson_id)
);
-- 演示用最简单的公开策略：生产环境请按自己需求收紧 RLS
alter table user_progress enable row level security;
create policy "open" on user_progress for all using (true) with check (true);
```
3. 在部署平台的环境变量里填 `VITE_SUPABASE_URL` 和 `VITE_SUPABASE_ANON_KEY`，重新部署。
4. 没填这两个变量时 App 自动只用本地存储，不会报错。

> 安全提醒：上面演示的 open 策略等于公开读写，只适合熟人小范围演示。正式给多人用时，请改成按 `user_name` 或 Supabase Auth 鉴权后再放行。

## 自由练习场 + 错题本（2026-10-30 新增）

全部存在浏览器 localStorage，0 服务器、0 费用。

自由练习场（顶部「自由练习场」）：
- 没有关卡、没有判题，写什么都能跑；附 3 个示例（打招呼、循环、统计词频）。
- 当前代码自动存为草稿，刷新不丢；觉得有用的代码可以起名字保存为片段，随时载入接着改、删除。

错题本（顶部「错题本」，有待复习数角标）：
- 只有“提交判题失败”才自动记进来，单纯点“运行”报错不算，避免把试错都记成错题。
- 同一关多次失败只记一条，失败次数累加，并更新为最新一次的代码和报错。
- 通关该关后自动变成“已攻克”；也可以手动标记已攻克、删除、清空已攻克。
- 复习顺序：失败次数多、上次失败久的排前面。点“去重练”会回到该关，编辑器直接载入上次失败的代码，改对提交后自动变已攻克。

## 调试题 + 重构题 + 项目关升级（2026-10-30 新增，总关数 29 → 35 关）

逻辑实战线从 8 关扩到 14 关，新增 6 关，仍在 `src/data/logicCourses.ts`：

- 调试题（3 关）：起手代码就是一段能跑但有 bug 的程序，先看症状再找错。
  买 2 件只算 1 件钱（循环里丢了 qty）、刚好 60 分也被算不及格（`<= 60` 和 `< 60` 的边界）、
  计数器每轮都被清空（初始化写进了循环里）。每关只修一个 bug。
- 重构题（3 关）：起手代码能跑、结果也对，但写得乱。行为不能变，把代码拆干净。
  长函数拆成 subtotal / apply_discount / add_tax 三个小函数、重复的加税逻辑抽成 add_tax、
  魔法数字换成 PASS_SCORE / ADULT_AGE 等有名字的常量。判题同时查行为和小函数/常量是否存在，
  直接提交起手代码会失败——这就是重构题和普通题的区别。
